# ABC Challenge Project (with local images)

## Project files
- `index.html` — A-Z webpage
- `style.css` — layout and required heading colours
- `script.js` — random text colour on heading click
- `images/` — 26 local SVG image files, one for each alphabet item

## Run
1. Extract the ZIP file.
2. Open the extracted folder in VS Code.
3. Open `index.html` in your browser (or use Live Server).

All 26 illustrations are included locally. No internet connection is needed for the images.
